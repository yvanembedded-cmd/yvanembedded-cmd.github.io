Project Overview

An EMG-controlled prosthetic hand using MyoWare muscle sensors and embedded actuation to achieve multi-degree-of-freedom finger motion for assistive robotics applications. The system reads surface EMG signals from forearm muscles and maps them to individual servo-driven finger joints in real time.

How It Works

  • EMG Acquisition: MyoWare 2.0 sensors placed on forearm flexor/extensor muscles capture muscle activation signals via analog output.
  • Signal Processing: ADC sampling + envelope detection + threshold classification determine intended finger motion.
  • Actuation: PWM signals drive micro servo motors at each finger joint, translating muscle intent to physical grip.
  • 5-DOF Mapping: Different gesture patterns activate independent finger channels, enabling pinch, grasp, and point gestures.
