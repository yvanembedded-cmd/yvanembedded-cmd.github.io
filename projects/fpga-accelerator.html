Project Overview

This project implements a 32×32 integer/fixed-point matrix multiplication accelerator on an FPGA using High-Level Synthesis (HLS). The design targets energy-efficient compute architectures relevant to AI inference workloads — the kind of hardware that powers neural network layers at the edge.

The accelerator was synthesized using Xilinx Vitis HLS and analyzed in Vivado for resource utilization and power consumption, exploring the fundamental trade-off between throughput (II, latency) and hardware resources (LUTs, DSPs, BRAM).

Design Approach

  • HLS Directives: Applied #pragma HLS PIPELINE and #pragma HLS UNROLL to the inner loop, achieving an initiation interval (II) of 1 for the innermost computation.
  • Memory Architecture: Input matrices are partitioned into on-chip BRAMs using array partitioning pragmas to maximize parallel memory access.
  • DSP Inference: Multiply-accumulate operations are mapped to dedicated DSP48 slices for area and power efficiency.
  • Throughput vs. Resource Analysis: Multiple synthesis configurations were compared, plotting throughput (GOPS) against LUT and DSP count to identify the Pareto-optimal design point.

Key Results

  • Achieved II = 1 for the innermost loop after applying pipeline and unroll directives.
  • Demonstrated clear trade-off curves between LUT utilization and throughput across 4 synthesis configurations.
  • Characterized power at different clock frequencies, demonstrating feasibility for edge AI deployment.
  • Validated functional correctness via co-simulation comparing HLS output against a software reference.
